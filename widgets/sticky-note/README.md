# 便签 · Sticky Note

iOS 主屏幕便签小组件，跑在 [Egern](https://egernapp.com) 上。
**填几行字就能用**：标题 + 8 行正文，留空的格不会显示。9 种纸张样式选一个就完事。

订阅地址：

```
https://raw.githubusercontent.com/a13609y/egern-modules/main/widgets/sticky-note/sticky-note.yaml
```

样式预览（浏览器近似渲染，只看配色和疏密）：[preview.html](preview.html)

---

## 三步用起来

1. Egern → 工具 → 模块 → `+` → 粘贴上面的地址 → 保存。
2. 打开模块的「参数」页，在 **第 1 行 / 第 2 行 / 第 3 行…** 里写你的内容，选个纸张样式，保存。
3. 主屏幕长按空白处 → `+` → 搜 Egern → 选小 / 中 / 大号 → 长按组件 → 编辑小组件 → 选「便签」。

> 改完参数没立刻变？把组件删掉重加一次（Egern 会缓存脚本）。

## 参数只有这些

| 参数 | 说明 | 示例 |
| --- | --- | --- |
| `标题` | 第一行，加粗 | `本周待办` |
| `第 1 行` ~ `第 8 行` | 正文，**留空就不显示** | `买牛奶和鸡蛋` |
| `纸张样式` | 9 选 1 | `paper` / `sticky` / `grid` … |
| `顶部装饰` | 强制统一装饰：`auto` 跟随样式 / `tape` 胶带 / `pin` 图钉 / `clip` 别针 / `none` 不要 | `auto` |
| `下划线` | `auto` 跟随样式 / `on` 每一行都加（标题不加）/ `off` 全部不要 | `auto` |
| `字号` | 默认 `15`，固定不变 | `15` |
| `对齐` | `center` 标题和正文一起居中（默认）/ `left` 全部靠左 | `center` |
| `锁屏字号` | 锁屏组件单独用的字号，9~32 | `15` |

小规则：

- 文字整体**垂直居中**，不会贴着顶部留下半屏空白。
- 行数少的时候**行距自动拉开铺满**（最多到字号的 2.2 倍，大号 2.8 倍），不会挤在顶上。
- 空行：那一行只写一个 `-`。
- 字号**不会为了塞内容而变小**。一行字太长，超出部分显示成 `…`，永远不换行。
- 行数超过组件能放下的量，末尾提示 `⋯ 还有 N 行`，写大号或调小字号就能多放。

行数上限：**小号 4 行、中号 4 行、大号 8 行**，超出直接不显示，没有多余提示。

## 纸张样式

| 样式 | 观感 | 纸色 | 默认横线 | 默认装饰 |
| --- | --- | --- | --- | --- |
| `paper` | 米白信纸 | `#FBF7EE` | 有 | 胶带 |
| `sticky` | 黄色便利贴 | `#FFF3A6` | 无 | 无 |
| `rose` | 粉色便签 | `#FFDCE5` | 无 | 胶带 |
| `memo` | 备忘录白 | `#FFFFFF` | 无 | 回形针 |
| `kraft` | 牛皮纸 | `#D9BE96` | 有 | 胶带 |
| `grid` | 方格纸 | `#F8FBFF` | 方格底纹 | 胶带 |
| `chalk` | 黑板 | `#2C3330` | 无 | 无 |
| `night` | 深蓝夜 | `#1E2A44` | 无 | 无 |
| `transparent` | 透明 + 细描边 | 透明 | 无 | 无 |

`transparent` 去掉背景只留 1px 描边（深浅色自动切换），适合配自己的壁纸。

## 锁屏小组件

同一个组件也能放到**锁屏**（iOS 16+）：锁屏长按 → 自定义 → 添加小组件 → 选 Egern → 选用矩形样式。

- 锁屏上**不显示标题**，只把正文记事一条条列出来。
- 锁屏的字号用参数里的 **`锁屏字号`** 单独调（默认 15，范围 9~32），和主屏幕的「字号」互不影响。
- 最多显示 **前 3 条**，再多也不会挤。
- 锁屏上不能有背景色和自定义颜色（系统统一按单色渲染），所以纸张样式只影响主屏幕。
- 圆形（accessoryCircular）显示前 2 条，内联（accessoryInline）显示第 1 条。

## 能放几行（字号 15 时）

| 尺寸 | 画布 | 正文行数 |
| --- | --- | --- |
| 小号 | 155×155 | 4 行 |
| 中号 | 329×155 | 4 行 |
| 大号 | 329×345 | 8 行 |

字号越大，能放下的行数越少；放不下时多出来的行直接不显示，而不去挤或缩字。

## 进阶：隐藏参数（想折腾才看）

界面上只放了上面 5 项，脚本其实还认这些键。它们不在 `env_schema` 里，模块设置页不显示；要用手动改 YAML 的 `scriptings.generic.env`（或自建本地脚本时传 env）：

| 键 | 作用 | 默认 |
| --- | --- | --- |
| `NOTE` | 多行正文（真换行），填了就忽略 `LINE1~8` | 空 |
| `BULLET` | 每行统一前缀，如 `•` `☐` | 空 |
| `COLOR` `INK` `ACCENT` `RULE` | 自定义纸色 / 字色 / 标题色 / 横线色 | 跟随样式 |
| `FONT` | `system` / `kaiti` 楷体 / `songti` 宋体 / `pingfang` 苹方 / `mono` | `system` |
| `ALIGN` | `left` / `center` / `right` | `left` |
| `LINES_S` `LINES_M` `LINES_L` | 各尺寸显示行数上限 | 4 / 4 / 8 |
| `FOOTER` | 底部小字（默认不显示，要开就手动填，支持 `{date}` `{weekday}` 等） | 空 |
| `REFRESH_HOURS` | 刷新提示间隔（小时） | `6` |
| `URL` | 点击组件打开的链接 | 空 |

## 已知限制

- 锁屏组件没有背景和自定义颜色（iOS 限制），只能显示纯文字，最多 3 条。
- 刷新是「提示」不是「保证」，iOS 自己决定何时重算；内容全是静态文字，所以刷新频率对观感没影响。
- 官方组件 DSL 没有行高和旋转属性，所以便签本身没法倾斜（只有胶带装饰带一点角度）。
