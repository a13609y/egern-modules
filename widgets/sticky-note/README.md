# 便签 · Sticky Note

iOS 主屏幕便签小组件，跑在 [Egern](https://egernapp.com) 上。
**文字全部由你自己在模块参数里填**，留空就不显示；9 种纸张样式随便挑，颜色 / 装饰 / 横线 / 字体 / 对齐都能单独改。

订阅地址：

```
https://raw.githubusercontent.com/a13609y/egern-modules/main/widgets/sticky-note/sticky-note.yaml
```

样式预览（浏览器近似渲染，仅看配色和疏密）：[preview.html](preview.html)

## 安装

1. Egern → 工具 → 模块 → `+` → 粘贴上面的地址 → 保存。
2. 打开模块的「参数」页，往下翻，**在 LINE1 / LINE2 … 里写你的内容**，写完保存。
3. 主屏幕长按空白处 → `+` → 搜 Egern → 选小 / 中 / 大号 → 添加。
4. 长按组件 → 编辑小组件 → 选「便签」。

> 改完参数如果没立刻变，把组件删掉重加一次（Egern 会缓存脚本）。

## 变量一览（按模块设置页的顺序）

### 一、内容

| 变量 | 作用 | 默认 | 示例 |
| --- | --- | --- | --- |
| `TITLE` | 标题，加粗显示在第一行 | 空 | `本周待办` |
| `LINE1` ~ `LINE8` | 正文第 1~8 行 | 空 | `买牛奶和鸡蛋` |
| `NOTE` | 一次写多行（里面直接回车）。**填了就忽略 LINE1~8** | 空 | 见下 |
| `FOOTER` | 页脚小字 | 空 | `{date} {weekday}` |
| `BULLET` | 统一加在每行开头的前缀 | 空 | `•` 或 `☐` |

规则：

- **留空就不显示**，不会留一条空白。
- 想留一个空行，那一行只写一个 `-`。
- 每一行都只占一行：字太长会自动缩小，缩到最小还长就截断，**绝不会换行把布局撑爆**。
- 放不下时会自动少显示几行，末尾给一个 `⋯ 还有 N 行` 的提示。想硬性限制行数用下面的 `LINES_S/M/L`。

`NOTE` 写法示例（模块参数里换行直接回车）：

```
买牛奶和鸡蛋
周三 10:00 牙医
-
给妈妈打电话
```

`FOOTER` 占位符：

| 写法 | 输出 |
| --- | --- |
| `{date}` | `11月5日` |
| `{md}` | `11/05` |
| `{weekday}` | `周四` |
| `{time}` | `14:30` |
| `{yyyy}` `{mm}` `{dd}` | `2026` `11` `05` |
| `{MM}` `{D}` | `11月` `5` |

页脚里带日期时，组件会在**次日凌晨 2 点**刷新一次，日期不会停在昨天。

### 二、外观

| 变量 | 作用 | 可选值 / 默认 |
| --- | --- | --- |
| `STYLE` | 纸张样式预设 | `paper`（默认）/ `sticky` / `rose` / `memo` / `kraft` / `grid` / `chalk` / `night` / `transparent` |
| `COLOR` | 自定义纸色 | 空 = 用样式默认，如 `#FFF2CC` |
| `INK` | 自定义文字颜色 | 空 = 用样式默认 |
| `ACCENT` | 标题 + 装饰用色 | 空 = 用样式默认 |
| `RULE` | 横线颜色 | 空 = 用样式默认 |
| `DECOR` | 顶部装饰 | `auto`（默认，跟随样式）/ `tape` 胶带 / `pin` 图钉 / `clip` 回形针 / `none` |
| `RULED` | 横线纸线条 | `auto` / `on` / `off` |
| `FONT` | 字体 | `system`（默认）/ `kaiti` 楷体 / `songti` 宋体 / `pingfang` 苹方 / `mono` 等宽 |
| `SIZE` | 正文字号 | `0` = 自动（按尺寸和行数缩放，最小 10pt），也可填 `12`~`16` |
| `ALIGN` | 文字对齐 | `left`（默认）/ `center` / `right` |

### 三、行为

| 变量 | 作用 | 默认 |
| --- | --- | --- |
| `LINES_S` | 小号最多显示几行 | `auto` |
| `LINES_M` | 中号最多显示几行 | `auto` |
| `LINES_L` | 大号最多显示几行 | `auto` |
| `REFRESH_HOURS` | 刷新提示间隔（小时） | `6` |
| `URL` | 点击组件打开的链接 / App scheme | 空 |

## 样式预设对照

| STYLE | 观感 | 纸色 | 字色 | 默认横线 | 默认装饰 |
| --- | --- | --- | --- | --- | --- |
| `paper` | 米白信纸 | `#FBF7EE` | 深褐 | 有 | 胶带 |
| `sticky` | 黄色便利贴 | `#FFF3A6` | 深黄褐 | 无 | 无 |
| `rose` | 粉色便签 | `#FFDCE5` | 深玫红 | 无 | 胶带 |
| `memo` | 备忘录白 | `#FFFFFF` | 近黑 | 无 | 回形针 |
| `kraft` | 牛皮纸 | `#D9BE96` | 深棕 | 有 | 胶带 |
| `grid` | 方格纸 | `#F8FBFF` | 墨蓝 | 无（方格底纹） | 胶带 |
| `chalk` | 黑板 | `#2C3330` | 米白 | 无 | 无 |
| `night` | 深蓝夜 | `#1E2A44` | 冷白 | 无 | 无 |
| `transparent` | 透明 + 细描边 | 透明 | 随系统深浅色 | 无 | 无 |

`transparent` 会去掉背景色，只留 1px 描边（深色模式自动换描边色），适合配自己的壁纸。

## 能显示多少行

组件高度固定，字号又要可读，所以每个尺寸能放的行数是有限的（自动模式下的实测值）：

| 尺寸 | 画布 | 正文大致行数 |
| --- | --- | --- |
| 小号 | 155×155 | 4~5 行 |
| 中号 | 329×155 | 5~6 行 |
| 大号 | 329×345 | 11~12 行 |

写的行数超过容量时会自动缩小字号去塞，塞不下就截断并提示。想固定行数用 `LINES_S/M/L` 硬性截断。

## 已知限制

- 不支持锁屏组件（accessory 系列），只会画在主屏幕。
- 刷新是「提示」不是「保证」，iOS 会按自己的节奏决定何时重算；但内容是静态文字，除了页脚日期外不影响观感。
- `FONT` 依赖系统内置字体（楷体/宋体/苹方），没装的机型会回退系统字体。
