# 节日倒数（Egern 小组件）

距离下一个节日还有多少天。三档尺寸同一套结构：**大数字 + 节日胶囊 + 「还没到的节日」网格**，只是字号和条数不同。

## 订阅

```
https://raw.githubusercontent.com/a13609y/egern-modules/main/widgets/holiday-countdown/holiday-countdown.yaml
```

Egern → 工具 → 模块 → `+` → 粘贴地址 → 保存 → 「分析 → 组件」里添加名为「节日倒数」的组件。
主屏幕长按 → `+` → Egern → 选尺寸 → 长按组件 → 编辑小组件 → 选「节日倒数」。

## 版面

| 尺寸 | 内容 |
| --- | --- |
| 小号 | 40pt 大数字 → 胶囊 → 两行两列 4 条（小寒 4天 / 大寒 19天 / 立春 34天 / 情人节 44天） |
| 中号 | 标题行 → 36pt 大数字 + 右侧胶囊 → 两行三列 6 条 |
| 大号 | 和中号同一套排版，字号放大：标题 13 → 节日名 17、数字 54、格子 12/16，条数 12 条（四行三列） |

- 数字和列表拉开差距：大数字 36–48pt，列表里的天数 10–15pt
- 当天显示「今天」（红色）
- 列表按分类着色：节气绿、现代节日金、传统节日主色，当天红色
- 列表里的天数 10–16pt，大数字 36–48pt，差距拉开

## 显示什么

- **法定与传统**：元旦、春节、元宵、清明、劳动节、端午、七夕、中秋、重阳、国庆、除夕
- **二十四节气**：小寒 → 冬至，共 24 个
- **现代节日**：情人节、妇女节、愚人节、青年节、表白日(5/20)、儿童节、教师节、万圣夜、光棍节、双十二、平安夜、圣诞节、跨年夜、母亲节、父亲节、感恩节
- **自定义纪念日**

一共 50 条候选，按「还有几天」升序排，能显示几条取前面几条。

## 参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `TITLE` | 节日倒数 | 大号/中号标题 |
| `TRANSPARENT` | false | 不画背景渐变，只保留一圈 `rgba(255,255,255,0.06)` 描边 |
| `THEME` | auto | auto / fest / weekend / workday |
| `GRID_ITEMS` | 12 | 大号网格条数（3-24），不含顶部那个大数字 |
| `SHOW_TERMS` | true | 是否显示二十四节气 |
| `SHOW_WESTERN` | true | 是否显示现代节日 |
| `ANNIVERSARIES` | 空 | `名字=05-20`（每年循环）或 `名字=2026-02-01`（只算一次） |

## 配色

背景三套，深浅色各一份，自动切换：

| 场景 | 浅色 | 深色 |
| --- | --- | --- |
| 工作日 | `#FFFFFF → #F2F2F7` | `#1C1C1E → #0C0C0E` |
| 周末 | `#F4F8FF → #E6F2FF` | `#111827 → #0B0F19` |
| 节日当天 | `#FFF8EC → #FFEFD5` | `#2A1F0E → #1A1208` |

胶囊和底部面板用 4%–6% 的黑/白叠加，不额外引入颜色。

## 数据从哪来

**完全不联网**：

- 农历节日（春节/元宵/端午/七夕/中秋/重阳/除夕）：内置 **2024–2050** 公历日期表
- 二十四节气：内置 **2024–2050** 日期表，清明表外年份用 21 世纪公式兜底
- 固定公历节日：直接算
- 母亲节 / 父亲节 / 感恩节：按「5 月第 2 个周日 / 6 月第 3 个周日 / 11 月第 4 个周四」现算

## 已知限制

- 不显示「连休几天 / 调休」，那部分每年由国务院公布，写死会过期。
- 预览页是近似渲染，字重与间距与真机有差异，最终以真机为准。
