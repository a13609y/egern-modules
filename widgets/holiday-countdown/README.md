# 节日倒数（Egern 小组件）

距离下一个节日还有多少天。**法定/传统节日 + 二十四节气 + 现代节日 + 自定义纪念日**，按天数自动排序，小号 / 中号 / 大号与三种锁屏组件都支持。

## 订阅

```
https://raw.githubusercontent.com/a13609y/egern-modules/main/widgets/holiday-countdown/holiday-countdown.yaml
```

Egern → 工具 → 模块 → `+` → 粘贴地址 → 保存 → 「分析 → 组件」里添加名为「节日倒数」的组件。
主屏幕长按 → `+` → Egern → 选尺寸 → 长按组件 → 编辑小组件 → 选「节日倒数」。

## 显示什么

| 分类 | 内容 | 颜色 |
| --- | --- | --- |
| 法定与传统 | 元旦、春节、元宵、清明、劳动节、端午、七夕、中秋、重阳、国庆、除夕 | 主色（黑/白） |
| 二十四节气 | 小寒 → 冬至，共 24 个 | 绿 |
| 现代节日 | 情人节、妇女节、愚人节、青年节、表白日(5/20)、儿童节、教师节、万圣夜、光棍节、双十二、平安夜、圣诞节、跨年夜、母亲节、父亲节、感恩节 | 金 |
| 自定义 | 你填的纪念日 | 主色 |

一共 50 条候选，按「还有几天」升序排，当天的显示「今天」、次日「明天」。
当天有节日时整卡换成暖橙背景。

## 参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `TITLE` | 节日倒数 | 左上角标题 |
| `TRANSPARENT` | false | 不画背景渐变，只保留一圈 `rgba(255,255,255,0.06)` 描边 |
| `THEME` | auto | auto / fest / weekend / workday |
| `GRID_ITEMS` | 15 | 大号最多显示几条（3-24，按 3 列排）；中号固定 7 条，小号 1 条 + 下三条 |
| `SHOW_TERMS` | true | 是否显示二十四节气 |
| `SHOW_WESTERN` | true | 是否显示情人节/光棍节/圣诞这类现代节日 |
| `ANNIVERSARIES` | 空 | `名字=05-20`（每年循环）或 `名字=2026-02-01`（只算一次） |

自定义纪念日示例：

```
恋爱纪念日=05-20,结婚纪念日=2026-02-01,爸爸生日=1968-09-12
```

## 数据从哪来

**完全不联网**，也不依赖任何接口：

- 农历节日（春节/元宵/端午/七夕/中秋/重阳/除夕）：内置 **2024–2050** 的公历日期表（`lunardate` 一次性生成）。
- 二十四节气（含清明）：内置 **2024–2050** 的日期表（`cnlunar` 生成），清明在表外年份用 21 世纪公式兜底。
- 固定公历节日：直接算。
- 母亲节 / 父亲节 / 感恩节：按「5 月第 2 个周日 / 6 月第 3 个周日 / 11 月第 4 个周四」现算，永远不会过期。

所以没有「接口挂了」「cookie 过期」「数据源改版」这些问题；唯一失效点是 2050 年之后节气与农历表用完，届时重新生成一遍即可（`test.mjs` 会跑到 2051 验证降级）。

## 渲染细节

- 时区固定按北京时间，用 UTC 天数做整数比较，绕开时区与夏令时误差。
- `refreshAfter` 设在**次日 00:02（北京时间）**，跨零点后数字会变。
- 颜色全部写成 `{light, dark}` 自适应，深色模式自动换配色。
- 布局与配色取自 lylywayr/NetWork-Module 的「时光倒数」；透明模式的做法参考 pronounAI/Egern。

## 文件

- `holiday-countdown.yaml` —— 模块清单（env_schema + widgets 声明）
- `holiday-countdown.js` —— 组件脚本（约 18KB，其中 2.6KB 是农历与节气表）
- `test.mjs` —— 21 条用例：天数排序、三种主题、透明模式、纪念日解析、节气/现代节日开关、浮动节日算法、跨年份、越界降级、刷新时间、各尺寸输出
- `gen-preview.mjs` → `preview.html` —— 把 DSL 转成近似 HTML 的渲染预览，改样式前先看这个

## 已知限制

- 不显示「连休几天 / 调休」——那部分每年由国务院公布，写死会过期，本模块故意不做。
- 锁屏组件只用纯文字，系统那边本身不支持背景。
- 预览页是近似渲染，字重、间距与真机有差异；最终效果以真机为准。
