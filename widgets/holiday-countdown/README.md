# 节日倒数（Egern 小组件）

距离下一个假期还有多少天。**两种排版**：`hero`（大天数 + 节日胶囊 + 七格假期条，参考图样式）和 `grid`（全部节日九宫格）。

## 订阅

```
https://raw.githubusercontent.com/a13609y/egern-modules/main/widgets/holiday-countdown/holiday-countdown.yaml
```

Egern → 工具 → 模块 → `+` → 粘贴地址 → 保存 → 「分析 → 组件」里添加名为「节日倒数」的组件。
主屏幕长按 → `+` → Egern → 选尺寸 → 长按组件 → 编辑小组件 → 选「节日倒数」。

## 两种排版

### hero（默认）

```
📅 距离下一个假期还有

   154 天
   ✈ 国庆节 · 10月1日

  元旦 | 春节 | 清明 | 劳动节 | 端午 | 中秋 | 国庆
  52天 |114天 |148天 | 165天 |177天 |243天 |154天
```

- 大字标题 + 超大天数（大号 92pt，中号 50pt）
- 半透明圆角胶囊显示下一个假期的名字和日期
- 底部一条带分隔线的七格假期条，大号和中号都有
- 假期取「元旦 / 春节 / 清明 / 劳动节 / 端午 / 中秋 / 国庆」七个，**固定按日历顺序排**，不是按天数

### grid

把一年里所有节日按「还有几天」升序排成网格，包括二十四节气和情人节、光棍节、圣诞这些现代节日：

- 大号：3 列 × 5 行 = 15 条（`GRID_ITEMS` 可调到 24）
- 中号：1 大 + 6 小 = 7 条
- 小号：1 条 + 底部「小寒 4 · 大寒 19 · 立春 34」
- 节气绿色、现代节日金色、法定与传统节日主色

## 参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `STYLE` | hero | `hero` 参考图排版 / `grid` 九宫格排版 |
| `TITLE` | 节日倒数 | 标题（仅 grid 排版使用） |
| `TRANSPARENT` | false | 不画背景渐变，只保留一圈 `rgba(255,255,255,0.06)` 描边 |
| `THEME` | auto | auto / fest / weekend / workday |
| `GRID_ITEMS` | 15 | grid 排版大号显示条数（3-24） |
| `SHOW_TERMS` | true | grid 排版是否显示二十四节气 |
| `SHOW_WESTERN` | true | grid 排版是否显示现代节日 |
| `ANNIVERSARIES` | 空 | `名字=05-20`（每年循环）或 `名字=2026-02-01`（只算一次） |

## 配色

背景三套，深浅色各一份，自动切换：

| 场景 | 浅色 | 深色 |
| --- | --- | --- |
| 工作日 | `#FFFFFF → #F2F2F7` | `#1C1C1E → #0C0C0E` |
| 周末 | `#F4F8FF → #E6F2FF` | `#111827 → #0B0F19` |
| 节日当天 | `#FFF8EC → #FFEFD5` | `#2A1F0E → #1A1208` |

胶囊和底部条用 5%–7% 的黑/白叠加，不额外引入颜色。

## 数据从哪来

**完全不联网**：

- 农历节日（春节/元宵/端午/七夕/中秋/重阳/除夕）：内置 **2024–2050** 公历日期表
- 二十四节气：内置 **2024–2050** 日期表，清明表外年份用 21 世纪公式兜底
- 固定公历节日：直接算
- 母亲节 / 父亲节 / 感恩节：按「5 月第 2 个周日 / 6 月第 3 个周日 / 11 月第 4 个周四」现算

## 已知限制

- 不显示「连休几天 / 调休」，那部分每年由国务院公布，写死会过期。
- 预览页是近似渲染，字重与间距与真机有差异，最终以真机为准。
