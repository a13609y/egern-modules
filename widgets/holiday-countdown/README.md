# 节日倒数（Egern 小组件）

距离下一个节日还有多少天。小号 / 中号 / 大号 + 三种锁屏组件，背景按「节假日 / 周末 / 工作日」自动换色，可选完全透明。

## 订阅

```
https://raw.githubusercontent.com/a13609y/egern-modules/main/widgets/holiday-countdown/holiday-countdown.yaml
```

Egern → 工具 → 模块 → `+` → 粘贴地址 → 保存 → 到「分析 → 组件」里添加名为「节日倒数」的组件。
主屏幕长按 → `+` → Egern → 选尺寸 → 长按组件 → 编辑小组件 → 选「节日倒数」。

## 参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `TITLE` | 节日倒数 | 左上角标题 |
| `TRANSPARENT` | false | 不画背景渐变，只保留一圈 `rgba(255,255,255,0.06)` 描边，壁纸透出来 |
| `THEME` | auto | auto = 节日当天暖橙、周末冷蓝、其余浅灰；也可强制 `fest` / `weekend` / `workday` |
| `GRID_ITEMS` | 8 | 大号最多显示几条（2-12）；中号固定 4 条，小号 1 条 |
| `ANNIVERSARIES` | 空 | 自定义纪念日，`名字=05-20` 每年循环，`名字=2026-02-01` 只算一次 |

自定义纪念日示例：

```
恋爱纪念日=05-20,结婚纪念日=2026-02-01,爸爸生日=1968-09-12
```

## 数据从哪来

**完全不联网**，也不依赖任何接口：

- 农历节日（春节、元宵、端午、七夕、中秋、重阳、除夕）：一次性生成好 **2024–2050** 的公历日期表，内置在脚本里。运行时只做查表，2050 年前不需要维护。
- 固定公历节日（元旦 1/1、劳动节 5/1、国庆 10/1）：直接算。
- 清明：21 世纪公式 `day = floor(yy×0.2422 + 4.81) − floor(yy/4)`，已用 2025–2028 校验过。

所以没有「接口挂了」「cookie 过期」「数据源改版」这些问题，唯一的失效点是 2050 年之后农历表用完 —— 届时重新生成一遍即可（`test.mjs` 里会跑到 2051 验证降级）。

## 渲染细节

- 日期按「还有几天」升序排，当天显示「今天」，次日显示「明天」。
- 时区固定按北京时间计算，用 UTC 天数做整数比较，绕开时区与夏令时误差。
- `refreshAfter` 设在**次日 00:02（北京时间）**，保证跨零点后数字会变。
- 颜色全部写成 `{light, dark}` 自适应，深色模式自动换配色。
- 背景配色取自 lylywayr/NetWork-Module 的「时光倒数」；透明模式的做法参考 pronounAI/Egern。

## 文件

- `holiday-countdown.yaml` —— 模块清单（env_schema + widgets 声明）
- `holiday-countdown.js` —— 组件脚本（约 15KB，其中 1KB 是农历表）
- `test.mjs` —— 15 条用例：天数/排序、三种主题、透明模式、纪念日解析、跨年份、越界降级、刷新时间、各尺寸输出
- `gen-preview.mjs` → `preview.html` —— 把 DSL 转成近似 HTML 的渲染预览，改样式前先看这个

## 已知限制

- 不显示「连休几天 / 调休」，那部分每年由国务院公布，写死会过期，本模块故意不做。
- 锁屏组件（accessoryCircular / Inline）只用纯文字，不画背景，系统那边本身也不支持。
- 预览页是近似渲染，字重、间距与真机有差异；最终效果以真机为准。
