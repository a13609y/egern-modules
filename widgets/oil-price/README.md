# 全国实时油价 · Egern 小组件模块

显示 92 / 95 / 98 号汽油与 0 号柴油价格，支持调价趋势提示，小号 2×2 田字格、中/大号横排卡片自动适配，深浅色自适应。

- 数据源：<http://m.qiyoujiage.com>（网页结构解析，站点改版可能失效，有缓存兜底）
- 支持尺寸：小号 `systemSmall`、中号 `systemMedium`、大号 `systemLarge`
- 组件名：**实时油价**

## 安装

1. Egern → 工具 → 模块 → `+` → 粘贴模块地址：

```
https://raw.githubusercontent.com/a13609y/egern-modules/main/widgets/oil-price/oil-price.yaml
```

2. 保存后在模块列表里点开该模块，在「参数」里填写地区。
3. 回主屏幕长按 → `+` → Egern → 选尺寸 → 长按组件 → 编辑小组件 → 选择「实时油价」。

## 模块参数

| 参数 | 说明 | 默认值 | 控件 |
| --- | --- | --- | --- |
| `region` | 地区，拼音或中文均可 | `hainan/haikou` | 文本框 |
| `SHOW_TREND` | 是否显示下次调价趋势 | `true` | 开关 |
| `REFRESH_HOURS` | 刷新间隔（小时，1~24） | `6` | 文本框 |

### 地区写法

以下写法都能识别：

- 拼音路径：`hainan/haikou`、`guangdong/shenzhen`、`beijing`
- 省份中文：`海南`、`广东`、`内蒙古`（取省级价格）
- 城市中文：`海口`、`深圳`、`乌鲁木齐`（自动补上所属省份）
- 省份+城市：`广东/深圳`、`广东深圳`

省份页始终存在，城市页不存在时会自动退回省级页，不会因此报错。

## 常见问题

**显示「获取失败」**：多为网络问题或站点临时不可用。脚本会保留上一次成功的数据继续显示。

**显示「地区参数错误」**：`region` 填的内容无法识别。改成一个省份中文名（如 `浙江`）最快。

**价格和加油站不一致**：站点为省份/城市均价参考值，不是某个油站的实际挂牌价。

**想直连不走代理**：可在自己的配置里加一条 `domain_suffix: qiyoujiage.com → DIRECT`。模块本身不写路由规则，避免改动你的分流。
