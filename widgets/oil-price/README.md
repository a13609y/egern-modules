# 全国实时油价 · Egern 小组件模块

92 / 95 / 98 号汽油与 0 号柴油实时油价，三套尺寸布局，深浅色自适应。

- 数据源：<http://m.qiyoujiage.com>（省份/城市网页解析，站点改版可能失效，失败回退上次缓存）
- 支持尺寸：小号 `systemSmall`、中号 `systemMedium`、大号 `systemLarge`（锁屏 accessory 尺寸仅显示单价）
- 组件名：**实时油价**

## 安装

1. Egern → 工具 → 模块 → `+` → 粘贴模块地址：

```
https://raw.githubusercontent.com/a13609y/egern-modules-hub/main/widgets/oil-price/oil-price.yaml
```

2. 保存后点开该模块，在「参数」里填地区（默认 `hainan/haikou`）。
3. 回主屏幕长按 → `+` → Egern → 选尺寸 → 长按组件 → 编辑小组件 → 选择「实时油价」。

## 三套布局

| 尺寸 | 布局 |
| --- | --- |
| 小号 | 顶部地区 + 刷新时间；重点油品胶囊 + 大号单价 + 最近调价涨跌；底部「日期 调价 · 还有 N 天」 |
| 中号 | 四油品价格卡一排 + 真实记录走势折线 + 右侧「最近调价 / 预计下轮窗口」两栏 |
| 大号 | 标题行 + 四油品大价格卡 + 大折线图 + 分隔线 + 左「调价信息」右「重点油品加满 N 升」金额（单价 × 升数） |

折线图是脚本内生成的 SVG（`data:image/svg+xml;base64,...`），不加载任何外部资源；配色取明暗背景都通用的中间调（橙线 + 半透明面积 + 灰轴线）。

## 参数

| 参数 | 说明 | 默认值 | 控件 |
| --- | --- | --- | --- |
| `region` | 地区，拼音或中文均可 | `hainan/haikou` | 文本框 |
| `SHOW_TREND` | 是否显示走势折线 / 调价信息 | `true` | 选项 |
| `FUEL` | 小号大数字 / 走势折线 / 加满金额使用的油品（92 / 95 / 98 / 柴油） | `95` | 选项 |
| `FULL_LITERS` | 「加满」按多少升计算 | `50` | 文本框 |
| `REFRESH_HOURS` | 刷新间隔（1~24 小时），系统调度尽力而为 | `6` | 文本框 |

### 地区写法

以下写法都能识别：`hainan/haikou`、`guangdong/shenzhen`、`beijing`（拼音路径）；`海南`、`广东`、`内蒙古`（省份）；`海口`、`深圳`（城市，自动补省份）；`广东/深圳`、`广东深圳`（省份+城市）。

省份页始终存在，城市页不存在时自动退回省级页，不会因此报错。参数写错（例如一串符号）时会明确显示「地区参数错误」，而不是悄悄用默认地区。

## 数据真实性与边界

| 显示项 | 来源 |
| --- | --- |
| 四种油品价格 | 站点页面实时解析（真实） |
| 标题里的地区名 | 站点页面 `<title>`（真实） |
| 「最近调价」方向与幅度 | 站点页面调价提示文本（真实，未做二次计算） |
| 「预计下轮窗口」日期与剩余天数 | 最近调价日 + **10 个工作日**推算（国内成品油调价规则），界面上标注「预计」，遇法定节假日可能偏差 1~2 天 |
| 走势折线 | **本脚本自己真实抓到的价格快照**：每次抓到的价格与上一条不同才记一「轮」，最多保留 12 轮；不足 2 个点显示「走势暂无历史」，不画假曲线 |
| 下一轮涨跌幅度 | 站点不提供原油变化率，因此**不预测**，只显示最近一次已公布的调整 |
| 「加满 N 升」金额 | 当前所选油品真实单价 × 升数，四舍五入到分 |

所以：新装第一天中号/大号的走势区是「暂无历史」，这是设计如此，不是故障；用上一两次调价周期后曲线会自己长出来。

## 常见问题

**显示「获取失败」**：多为网络问题或站点临时不可用，脚本会保留上一次成功的数据继续显示（大号底部会标「缓存数据」）。

**显示「地区参数错误」**：`region` 认不出来，改成一个省份中文名（如 `浙江`）最快。

**组件不刷新**：`refreshAfter` 只是给系统的建议，WidgetKit 实际调度由 iOS 决定；改完参数后切换一次尺寸或下拉锁屏可以强制重绘。

**价格和加油站不一致**：站点是省份/城市均价参考值，不是某个油站挂牌价。

**想直连不走代理**：在自己的配置里加 `domain_suffix: qiyoujiage.com → DIRECT`。模块本身不写路由规则，避免改动你的分流。
