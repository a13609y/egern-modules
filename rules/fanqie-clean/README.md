# 番茄小说净化（隐藏短剧 / 福利）

**跟去广告模块分开的第二个模块**：去广告是「断路」，这个是「删数据」。

```
https://raw.githubusercontent.com/a13609y/egern-modules/main/rules/fanqie-clean/fanqie-clean.yaml
```

Egern → 模块 → 加这个 URL。装完在模块设置里能看到开关：

| 开关 | 默认 | 作用 |
|---|---|---|
| 隐藏短剧入口 | **开** | 删掉「短剧」tab、「剧场」卡片 |
| 隐藏福利 / 金币 / 签到 | **开** | 删掉签到、宝箱、金币、提现、红包、任务入口 |
| 清空活动中心 | **开** | 活动页列表清空 |
| 清理阅读页广告段 | **开** | 只删 JSON 里带广告标记的段落，不按文字删正文 |
| 调试日志 | 关 | 打开后日志里能看到每个接口删了什么 |

## 原理

短剧 / 福利这些**入口不是网络请求**，是 App 拿到首页配置 JSON 后自己画出来的。所以拦域名没用（拦了显示空白），只能改它收到的 JSON：

```
App 请求配置接口 → Egern 解密 → 脚本删掉指定字段 → App 按剩下的画
```

脚本只做「删数据」，不改协议、不伪造请求，删错了最多是页面少一块，关掉模块立刻恢复。

## 出处

脚本移植自 [Xhy333/QuantumultX](https://github.com/Xhy333/QuantumultX) 的 `ZDH/fqnovel-clean.js`（QX / Surge / Loon 通用，按名字和结构关键字判断，宁可少删不乱删）。移植只做了两件事：改成 Egern 的 `export default (ctx)` 入口，把写死的配置项接到模块开关上。**过滤逻辑原样保留。**

原脚本的保留名单里「短剧」是留下的，本模块把它做成了开关，默认按使用需求关掉。

## 注意

- 需要**装 Egern 根证书**并开启 MITM，否则脚本不生效（不会报错，也不会坏）。
- MITM 只开了 `api*-normal*.fqnovel.com` 和 `reading.snssdk.com`，没有放大到整个 `fqnovel.com`——图片、正片、日志域保持不加密，避免拖慢加载。
- 配置有客户端缓存，改完开关要**杀掉番茄重开**才看得到。
- 番茄版本更新改了字段名，某一块可能就不生效了，把「调试日志」打开看日志即可发现。
